## Entry

> Tell make.fun your idea in one plain description and an AI agent will build your first app, so you can try it, change it with words, and see if it fits — no coding needed.

- One sentence, 171 characters (UTF-8), within the 1–240 gate.
- Why it was picked: it gives a concrete reason to say yes now
  (one plain description → a first app you can try), makes handing
  over the idea feel easy and low-risk (try it, change it with
  words, see if it fits), and closes the coding barrier
  (no coding needed) — in plain words, with no overpromise
  (no cost / guarantee claims).

## How it was chosen (Forge, r5)

- 45 fresh one-sentence candidates written from the kit + inbox only
  (all 137–165 characters, all within the gate).
- Shortlist of 8 duelled blind, two-way (both orders), against
  3 anchors: weak (44 chars, generic), mid (140 chars), strong
  (171 chars: plain words + working first version + free + watch).
- Winner is a refinement of candidate #30, adding “no coding needed”.
- Blind-duel game scores for the winner (mean of the two orders,
  margin 1 = 0.6, margin 5 = 1.0 per call):
  vs weak anchor 1.00 (margins 5, 5),
  vs mid anchor 0.80 (margins 3, 3),
  vs strong anchor 0.75 (margins 3, 2) — above the 0.70 bar.
